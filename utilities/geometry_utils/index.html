aspect_ratio(A, B, C)

Computes the aspect ratio of triangle ABC, defined as the ratio between the circumradius to twice the inradius. This ratio equals 1 for equilateral triangle and goes to zero as the triangle gets close to degenerate.

Parameters:

Name Type Description Default
A Vec

first point of the triangle

 required

 required

 required

Returns:

closest_point_on_segment(P, A, B)

Computes the closest point from p on segment [A;B], and the feature of the segment on which it lies.

Parameters:

Name Type Description Default
P Vec

Query point

 required
A Vec

First segment extremity

 required
B Vec

Second segment extremity

 required

Returns:

Name Type Description
Vec

the point Q on [A;B] that minimizes its distance with P.
int

the feature of the segment on which Q lies: 0 if Q is in the interior of the segment, 1 if Q is the extremity A, 2 if Q is the extremity B.

closest_point_on_triangle(P, A, B, C)

Computes the closest point from point p to triangle ABC, and the feature of the triangle on which it lies. Uses the Voronoi region tests from Ericson, Real-Time Collision Detection, section 5.1.5.

Parameters:

Name Type Description Default
P Vec

Query point

 required
A,B,C Vec

vertices of the triangle

 required

Returns:

Name Type Description
Vec

the point Q in triangle ABC that minimizes its distance with P.
int

the feature of the triangle on which Q lies: 0 if Q is in the interior of the face, 1, 2 or 3 if Q is the vertex A, B or C respectively, 4, 5 or 6 if Q is in the interior of the edge AB, BC or CA respectively.
